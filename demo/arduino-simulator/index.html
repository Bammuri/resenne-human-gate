      MODE 3 · CUSTOM
      커스텀 버튼 설정
      
        
      버튼 1–7의 이름, 실행 대상과 기능을 저장하세요. 8번 버튼은 항상 MODE입니다. 웹 AI는 실행 중인 Codex·Claude, 기존 Codex는 외부 세션에 메시지를 전달합니다.
      
        
      
            

      
        
      Arduino + BindDeck 연결하기
      UNO R4 WiFi · A0 가변저항 · DFPlayer Pro 구성입니다.
      Arduino 코드 ↓Wi-Fi 설정 헤더 ↓
      
        
      1. BindDeck 배선키 1–8은 D2–D9와 GND에 순서대로 연결합니다. 버튼은 INPUT_PULLUP이며 A0 가변저항은 5V·와이퍼(A0)·GND에 연결합니다. D0/RX ↔ DFPlayer TX, D1/TX ↔ DFPlayer RX를 연결합니다. D10은 330~470Ω 저항을 거쳐 WS2812B LED 8개의 IN에 연결합니다.
      2. 키 기능1–7번은 현재 모드의 기능, 8번(D9)은 MODE입니다. AI 제어 → AI-DLC → 커스텀 순서로 전환합니다. 질문 대기 중 1–7번은 화면의 보기 번호를 선택합니다.
      3. 코드 업로드Arduino UNO R4 Boards의 UNO R4 WiFi와 USB 포트를 선택하고 simulator_r4.ino를 업로드합니다.
      4. 노브와 연결모드 1에서는 선택한 버튼에 따라 노브 기능이 바뀝니다. MODEL 선택 중에만 추론 강도를 조절합니다. AI-DLC에서는 자율성을 바꿉니다. IDE 시리얼 모니터를 닫고 실물 → USB 보드 연결에서 포트를 선택합니다.
      
        
      참조 BindDeck의 ESP32 회로를 그대로 복제하는 것이 아니라, 키·OLED·노브 레이아웃을 Arduino 핀에 맞춘 Button Lab 프로필입니다. USB 또는 Wi-Fi로 연결합니다. 공유기 설정은 보드 설정 페이지에서, 보드 IP는 OLED에서 확인합니다. A0 가변저항에는 누름 기능이 없습니다.
