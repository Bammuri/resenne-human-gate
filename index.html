실물 BindDeck 연결하기

BindDeck(ESP32) 매크로패드와 USB 데이터 케이블을 준비하세요.

펌웨어 코드 ↓
  1. 펌웨어 업로드Arduino IDE에 ESP32 보드 패키지와 Adafruit SSD1306 · Adafruit GFX · Bounce2 라이브러리를 설치하세요. ESP32 보드와 USB 포트를 선택하고 다운로드한 binddeck_claude.ino를 업로드합니다. 이 펌웨어는 BLE·Wi-Fi를 사용하지 않으며 자격 증명을 담지 않습니다.
  2. Claude 세션 시작웹 터미널에서 Claude 시작을 누르거나 터미널에 claude를 실행하세요. 승인 프롬프트가 뜨면 버튼으로 답할 수 있습니다.
  3. 브라우저에서 연결다른 시리얼 모니터를 닫고, 데스크톱 Chrome에서 이 페이지를 여세요. 실물 BindDeck · USB → USB BindDeck 연결을 누른 뒤 보드 포트를 선택합니다.
  4. 버튼으로 응답BTN:0=YES(Enter), BTN:1=NO(Esc), BTN:2=STOP, 엔코더 회전=메뉴 이동, 엔코더 누름=ENTER 로 매핑됩니다. OLED에는 Claude 상태와 마지막 응답이 표시됩니다. 재업로드 전에는 USB 연결을 해제하세요.

실물 모드는 USB 시리얼만 사용합니다. Wi-Fi·BLE 설정은 필요하지 않습니다. 버튼 입력은 사람이 직접 누를 때만 Claude로 전송되며, 자동 승인은 하지 않습니다.
